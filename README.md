# UPI Transaction Fraud Detection & Analysis

## 📌 Project Overview

This project focuses on analyzing UPI transactions to identify
fraud patterns, transaction behavior, and potential risk indicators.

The project uses Python, Pandas, and PostgreSQL to perform data
cleaning, analysis, database management, and SQL-based insights.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- PostgreSQL
- SQL
- Jupyter Notebook
- Git & GitHub

## 📂 Datasets

The project contains four main datasets:

- `transactions.csv`
- `users.csv`
- `merchants.csv`
- `fraud_labels.csv`

A `data_dictionary.csv` is also included to describe the dataset
columns.
